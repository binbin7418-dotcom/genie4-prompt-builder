FAQ

What is Genie 4?

DeepMind's latest world model (announced October 27, 2026): it generates a real-time, steerable world from text, with native audio and a Gemini agent checking each step. You change weather, camera and events by typing while it runs.

How do I get access?

Research preview for trusted testers today. Google lists Project Genie (Google AI Ultra) and Gemini API early access as coming soon; a Project Genie waitlist is open. Nobody outside the tester group can run it yet — which is exactly why prompt libraries are being built now.

Why does the turning event matter so much?

A static scene is a video. A scene that reacts — rain arriving, a character entering, the tide turning — is a world. Genie 4's steering is the feature; prompts that plan the change get visibly more alive results.

Can I use these prompts commercially?

The library is yours to use in your own projects. Genie 4's own output terms are set by Google and may change at launch.

When will Genie 4 be available to the public?

As of November 2026, Genie 4 is limited to trusted testers. DeepMind has announced Project Genie access for Google AI Ultra subscribers and early Gemini API partners as coming soon, with a waitlist.

Can you steer a Genie 4 world while it is running?

Yes. Genie 4 supports real-time text steering: you type turning events and directions while the world runs, and the world adapts. This builder includes a turning-event sequencer for planning those interventions.

Does Genie 4 generate audio?

Yes. Genie 4 generates native audio matched to the world; Genie 3 worlds were silent. Prompts can specify ambience and signature sounds as part of the world seed.

What is a World Bible for Genie 4?

A World Bible is a one-page consistency sheet — world rules, art direction, physics and recurring landmarks — that you attach to every prompt so a series of worlds stays coherent. A fill-in template is included in the prompt library pack.

How long should a Genie 4 prompt be?

Two to four sentences is the sweet spot for a world seed: place, art direction, physics and one signature detail. Save longer text for turning events, which carry the story after the world starts.

What is the difference between Genie 3 and Genie 4?

Genie 4 adds native audio and real-time text steering. Genie 3 worlds were silent and could mainly be explored by moving; Genie 4 worlds can be redirected by typed events as they run.

Is Genie 4 free to use?

No public pricing has been announced yet. The announced access routes are a Google AI Ultra subscription through Project Genie and Gemini API partnerships. This builder is a free independent tool and is not affiliated with Google DeepMind.
