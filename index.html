FAQ

What is Genie 4?

DeepMind's latest world model (announced October 27, 2026): it generates a real-time, steerable world from text, with native audio and a Gemini agent checking each step. You change weather, camera and events by typing while it runs.

How do I get access?

Research preview for trusted testers today. Google lists Project Genie (Google AI Ultra) and Gemini API early access as coming soon; a Project Genie waitlist is open. Nobody outside the tester group can run it yet — which is exactly why prompt libraries are being built now.

Why does the turning event matter so much?

A static scene is a video. A scene that reacts — rain arriving, a character entering, the tide turning — is a world. Genie 4's steering is the feature; prompts that plan the change get visibly more alive results.

Can I use these prompts commercially?

The library is yours to use in your own projects. Genie 4's own output terms are set by Google and may change at launch.
